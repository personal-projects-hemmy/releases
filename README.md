# Releases

Downloadable builds of apps made by Philibert Hemmy Ramananjato.

This repository only hosts installers and update files. The source code is not published here.

## Apps

| App | Platform | Description |
| --- | --- | --- |
| **Focus** (Pomodoro) | Windows | A Pomodoro timer with projects, tasks and focus stats. |

## How to install

1. Open the [Releases](../../releases) page.
2. Download the latest installer for your app (for example `pomodoro-x.y.z-setup.exe`).
3. Run it. Apps that support in-app updates will check this repository for new versions automatically.
